# Motor-AntiFraude

Projeto Integrador, a equipe atuará como o núcleo de Engenharia de Dados e Inteligência Antifraude de uma FinTech submetida a uma auditoria do Banco Central.

Objetivo: desenvolver e apresentar um pipeline computacional e matemático automatizado em Python capaz de
auditar quatro camadas críticas de operação

* A telemetria lógica de segurança dos dispositivos em baixo nível
* A integridade relacional das bases cadastrais
* O comportamento estatístico-probabilístico das transações
* A topologia em grafos do fluxo monetário.
